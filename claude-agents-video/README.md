# Claude Agents — The Complete Visual Guide (Build It Step by Step)

**Prepared by Sara Salem**

A 9-minute 44-second professional motion-graphics video (1920×1080, 30 fps) explaining Claude agents and how to build one
in 8 steps — with 3D animation, animated graphs (agent loop, design-pattern diagrams, evaluation chart), an **American English
voice-over**, background music, and Sara Salem's photo in the closing scene.

## How it is made
Same pipeline as the other videos: `narration.json` → `tts.py` (Kokoro TTS, voice `af_heart`) → `timing.json`;
`src.html` + `base.css` + `extra.css` → `build.py` → `index.html`; `render.mjs` (Playwright → ffmpeg); `music.py`.
Audio files are regenerated by the scripts and not committed.
