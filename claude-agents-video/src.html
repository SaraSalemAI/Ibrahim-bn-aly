Chapter 01

Chatbot vs. Agent

Chatbot

Answers one message at a time
Waits for you after every reply
Can't take action on its own
You do the work it suggests

Agent

Starts from a goal & plans the work
Uses tools & takes actions
Checks its own results
Keeps going until the job is done
A chatbot talks — an agent gets things done
Chapter 02

What is an Agent?

A model like Claude using tools in a loop to work toward a goal — with a high degree of independence.
Claude = the brain — reasons, plans & decides
Tools = the hands — search, files, code, APIs
Context, memory & guardrails keep it focused & safe
ToolsThe hands
ContextWhat it knows
MemoryNotes over time
GuardrailsStay safe

Define the Job

Great Agent Task

Several steps to complete
Needs tools or data
A clear definition of “done”
Real time saved by automating

Not a Fit (Yet)

Simple one-shot questions
No clear finish line
Irreversible actions with no review
Success you can't measure
Write it down: goal · inputs · expected output · success measure
