## How it is made
Same pipeline as `claude-mcp-finance-video/`: `narration.json` → `tts.py` (Kokoro TTS, voice `af_heart`) → `timing.json`;
`src.html` + `base.css` + `extra.css` → `build.py` → `index.html`; `render.mjs` (Playwright → ffmpeg); `music.py`.
Audio files (`voice.wav`, `soundtrack.wav`) are regenerated by the scripts and not committed.
