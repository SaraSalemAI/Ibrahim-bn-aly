Why Do We Need Plugins?

Without Plugins

Everyone sets up Claude alone
Commands & agents in scattered files
Tool connections configured by hand

With Plugins

Everything packaged in one bundle
Installed with a single command

Chapter 02

What is a Plugin?

A package that extends Claude — a folder with a standard structure Claude knows how to read.
A manifest: plugin.json — name, version, description
Components: commands, agents, skills, hooks & MCP
Install it — Claude gains everything inside. Turn it off — gone.
