# Sample upload files — SYNTHETIC

Generated by `node tools/make-samples.js` from the demo generator. **These are not SUMED data.** Every file name starts with `SAMPLE_SYNTHETIC_` and every row carries a `Data Note` column.

Use them to test **Upload & Validate**: drag all files onto the drop zone, review the detected classification and column mapping, then *Validate & load*. Dates are written DD/MM/YYYY (the default ambiguous-date order).

- CSV files: supplier master, invoice register (+ lines), payment register, bank statement, bank accounts, FX rates, tax configuration, users, bank-change log, supplier documents, contracts, disputes, expected collections, other outflows, GL/AP summary, evaluations.
- `SAMPLE_SYNTHETIC_Procurement_Workbook.xlsx`: PRs, RFQs, POs, PO lines, GRNs, GRN lines and budget on separate sheets.
- `SAMPLE_SYNTHETIC_Invoice_INV-SMPL-0042.pdf`: a text-layer invoice for the OCR / extraction review screen.
