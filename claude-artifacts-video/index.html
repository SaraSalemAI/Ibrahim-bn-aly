Chapter 01

What are Artifacts?

Artifacts are standalone pieces of content Claude creates in a dedicated window beside your chat — so you can see, use and refine them instantly.
A separate panel that lives next to the conversation
Rendered live — run code, view pages, click buttons
Editable, versioned, downloadable & shareable

6 Core Artifact Types

  

  

    
Code
Snippets, scripts & full programs in any language — with syntax highlighting.
Python · JS · SQL

    
Documents
Markdown reports, guides, articles, plans & study notes you can copy or download.
text/markdown

Chapter 04

    
When Does Claude Create an Artifact?

  

  

    

      
Becomes an Artifact

      
Substantial content (roughly 15+ lines)

      
Self-contained & makes sense on its own

      
Something you'll edit, iterate or reuse

      
Meant to be used outside the chat

    

    

      
Stays in the Chat

      
Short answers & quick facts

      
Explanations & conversation

      
Tiny code snippets & examples

      
Content that depends on the chat context

    

  

  
Pro tip: just ask — “Put this in an artifact”

Chapter 09

    
6 Pro Tips for Better Artifacts

  

  

    
1
Be Specific
Describe layout, colours, data & behaviour

    
2
Name the Type
“Create a React artifact…” or “an SVG logo…”

    
3
Iterate in Small Steps
One clear change per message works best

    
4
Use Version History
Compare versions & restore the best one

    
5
Bring Your Data
Upload files or paste content as input

    
6
Let Claude Fix Errors
Hit “Try fixing” when something breaks
