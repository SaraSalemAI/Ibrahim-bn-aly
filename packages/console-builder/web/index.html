Spec reference

  • commands[].name is one or more words (deploy app); args are { name, type: string|number|boolean|enum, positional, required, rest, alias, choices, default }.
  • Text uses {arg} for arguments and {$var} for variables; top-level vars sets initial values.
  • Actions: print, table, kv, calc, set, http, open, run (macro), choice, date.
  • Every console has help, clear, echo, set, unset, vars, calc, history. Chain with && or ;.
  • theme: { background, foreground, accent }; welcome and prompt customise the terminal.
