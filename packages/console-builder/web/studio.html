        Spec reference

        • commands[].name is one or more words; args take type string, number, boolean or enum.
        • {arg} inserts an argument, {$var} a variable.
        • Actions: print table kv calc set http open run choice date, and for data query stats columns.
        • datasets holds tables by name; query filters with where such as units>10 and region=cairo.
        • Built in: help clear echo set unset vars calc history. Chain with && or ;.
        • Keys: Tab completes, ↑↓ history, Ctrl+L clears.
