Spec reference

  • commands[].name is one or more words, such as deploy app.
  • args: { name, type: string | number | boolean | enum, positional, required, rest, alias, choices, default }.
  • Text fills {arg} from arguments and {$var} from variables; top-level vars sets starting values.
  • Actions: print, table, kv, calc, set, http, open, run (a macro of other commands), choice, date.
  • Every console has help, clear, echo, set, unset, vars, calc and history. Chain with && (stops on error) or ;.
  • theme takes { background, foreground, accent }; welcome and prompt customise the terminal.
  • In the terminal: Tab completes, ↑ ↓ recall history, Ctrl+L clears.
