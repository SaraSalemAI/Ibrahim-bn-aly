# Claude Cowork — The Complete Visual Guide (All Types & Build It Step by Step)

**Prepared by Sara Salem**

A 8-minute 41-second professional motion-graphics video (1920×1080, 30 fps) on Claude Cowork — what it is, how it
works, all the types of work it can do (files & documents, research, data & spreadsheets, presentations, browser tasks,
scheduled tasks), its four building blocks, and 9 build steps from setup to a scheduled workflow — with 3D animation,
animated graphs, an **American English voice-over**, background music, and Sara Salem's photo in the closing scene.

▶ **Video:** [`claude-cowork-by-sara-salem.mp4`](claude-cowork-by-sara-salem.mp4)

## How it is made
Same pipeline as the other videos: `narration.json` → `tts.py` (Kokoro TTS, voice `af_heart`) → `timing.json`;
`src.html` + `base.css` + `extra.css` → `build.py` → `index.html`; `render.mjs` (Playwright → ffmpeg); `music.py`.
