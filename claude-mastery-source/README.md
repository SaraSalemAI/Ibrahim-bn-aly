# Claude Mastery — source

Continue building in Claude Code:
1. Unzip, `cd claude-mastery-source`, run `claude`.
2. Claude reads CLAUDE.md. Ask: "/plan Add [feature] to the platform".
3. `bash build.sh` then open `out.html` in a browser.
4. Publish `out.html` as an artifact (or upload it to any static host).
