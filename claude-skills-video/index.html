Chapter 01

What are Skills?

A Skill is a folder of instructions, scripts and resources that Claude can discover and load when a task needs it.
Built around one file: SKILL.md
Packages procedural know-how — the “how we do it” of a task
Claude picks the right skill automatically — no need to ask

4

Linked Resources

Point to scripts & files Claude can open or run

Build Once, Use Everywhere

Claude Code: place skills in .claude/skills/ or install plugins
Claude API & Agent SDK: add skills to your own agents

Chapter 08

Skills vs. Other Features

Skills

“How to do it”
LOADSOn demand, when relevant
BEST FORRepeatable workflows & expertise

Projects

“What to know”
LOADSAlways, inside that project
BEST FORBackground files & context

MCP

“What to reach”
LOADSLive connections to tools
BEST FORExternal apps & data

Prompts

“Just this once”
LOADSIn a single conversation
BEST FOROne-off requests
Better together: MCP gives access — Skills teach the procedure
